Installation & Setup
1. Clone the repository
bash
git clone https://github.com/abigaelmoraa/august-coding-robotics-registration.git


2. Install dependencies
bash
npm install

3. Set up environment variables
Create a `.env` file and add:

DATABASE_URL
API_KEY


4. Run the development server
```bash
npm run dev
 How to Use

1. Open the application in your browser
2. Fill in the registration form
3. Select your preferred program (Coding / Robotics)
4. Submit your details
5. Admin reviews and manages registrations

Admin Features

- View all registered students
- Filter by program type
- Export data (CSV/PDF optional)
- Manage program schedules
